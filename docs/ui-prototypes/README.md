# UI prototypes

These files preserve approved or in-progress visual design work so it can be reviewed from another computer.

## Conferences catalog v1

- File: `conferences-catalog-v1.html`
- Status: design draft; not yet implemented in the production application.
- Scope: desktop-first Conferences catalog with Grain-style application navigation, Table/Timeline/Regional views, search, clickable KPI filters, vertical filters, and decision filtering.
- Data rule: the prototype uses the repository's verified conference names and visible demo-workspace decisions; it must not be treated as a live data source.
- Reference influence: interaction ideas were adapted from the separately reviewed conference catalog reference, without copying its branding or unsupported data.

Open the HTML file directly in a browser for portable review. Production implementation requires separate approval and must preserve the application's scoring, evidence, Prep, AI, and workspace contracts.
